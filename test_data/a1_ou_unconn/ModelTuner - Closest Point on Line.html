I have points s, a, b in the n-dimensional space, with |b-a|=m. I want to find the point c, closest to the (0, s) line, for which |c-a|=m and |dot((b-a)/m, (c-a))/m|<=d. Here, d and m are given constant numbers.

Below is a self-contained derivation and a recipe you can drop into code.

1. Rewrite the problem with unit-length vectors

  • Radius      :  m = ‖b–a‖ (given)

  • Unit vector a→b :  p̂ = (b–a)/m

  • Line through 0, s :  L_s = { τ ŝ | τ∈ℝ },  where ŝ = s / ‖s‖

Look for

ini
c = a + m u,            (1)

with

csharp
‖u‖ = 1                                 (lies on the sphere S(a,m))
|u·p̂| ≤ d                              (angle restriction)

and which minimises the distance to L_s

r
dist(c, L_s) = ‖(I – ŝ ŝᵀ) c‖.         (2)

2. Decompose every vector w.r.t. ŝ

Put an orthonormal basis with ŝ as the first axis:

makefile
a   = a∥ ŝ + α,      α ⟂ ŝ
p̂  = p∥ ŝ + β,      β ⟂ ŝ
u   = u∥ ŝ + r w,    w ⟂ ŝ,  ‖w‖=1,  r = √(1−u∥²).

α, β live in an (n–1)-dimensional space.
Define the two scalars we shall need once:

ini
A = ‖α‖                    (distance of a from the line L_s)
B = (β·α)/A                (how much p̂'s perpendicular part points toward α)

3. Objective in these coordinates

Because (I – ŝ ŝᵀ)ŝ = 0, the distance (2) depends only on the component orthogonal to ŝ:

dist² = ‖α + m r w‖².

For any fixed length r the best direction is to take w opposite to α, i.e. w* = −α/A. Plugging this choice in,

dist(r) = | A − m r |.                    (3)

So without the angle constraint we would simply use

bash
r⋆ = min(A/m, 1)                          (4)

and the corresponding distance would be |A−m| (if A≥m) or 0 (if A≤m, the sphere already crosses the line).

4. Reduce the constraint to a single variable

With w = −α/A the dot-product constraint becomes

| u·p̂ | = | u∥ p∥ − r B | ≤ d,           (5)

and r² = 1 − u∥². Therefore the whole problem is now one-dimensional:

choose u∥ ∈ [−1,1] to
minimise g(u∥) = | A − m √(1−u∥²) |
subject to h(u∥) = | u∥ p∥ − √(1−u∥²) B | ≤ d.  (6)

5. Closed-form solution in two common cases

Geometry of a vs. the sphereFeasibility checkResult
Case 1: A ≥ m (line is outside the sphere)Try u∥ = 0, r = 1.
`h(0) =		−B
Case 2: A ≤ m (line intersects the sphere)Use r = A/m, so √(1−u∥²) = √(1−(A/m)²).
Pick the sign of u∥ (±) that reduces `		u·p̂

If the test fails in either case, the optimum lies on the boundary h(u∥)=d. Solving h(u∥)=d together with the identity r² = 1 − u∥² gives a quadratic

(p∥² − B²) u∥² ± 2 d p∥ u∥ + (d² − B²) = 0,       (7)

(chose the sign ± so that the term inside |…| matches the sign of u∥ p∥ − r B). Select the root lying in [−1,1]; this fixes r = √(1−u∥²). With that pair (u∥, r) plug back into (3) for the distance and into (1) for the point:

ini
u  = u∥ ŝ − r α/A
c  = a + m u.                                      (8)

The resulting c is the closest admissible point.

import numpy as np

def closest_c(a, b, s, m, d, tol=1e-12):
    """Return the point c that minimises distance to line (0,s)
       subject to |c-a| = m  and  |< (b-a)/m , (c-a) >/m| ≤ d.
    """
    a, b, s = map(np.asarray, (a, b, s))
    p_hat = (b - a) / m
    s_hat = s / np.linalg.norm(s)

    # Decompose a and p̂
    a_par = np.dot(a, s_hat)
    alpha = a - a_par * s_hat
    A = np.linalg.norm(alpha)

    p_par = np.dot(p_hat, s_hat)
    beta  = p_hat - p_par * s_hat
    B     = 0.0 if A < tol else np.dot(beta, alpha) / A

    # Helper to test feasibility of given u_parallel
    def feasible(u_par):
        r = np.sqrt(max(0.0, 1.0 - u_par**2))
        return abs(u_par * p_par - r * B) <= d + tol

    # ---------- case analysis -----------------
    if A >= m and feasible(0.0):
        # Case 1
        u = -alpha / A          # r = 1, u_parallel = 0
    elif A <= m:
        r_star = A / m
        u_par_opts = (+np.sqrt(1 - r_star**2), -np.sqrt(1 - r_star**2))
        ok = [u_par for u_par in u_par_opts if feasible(u_par)]
        if ok:
            u_par = ok[np.argmin(np.abs(ok))]   # pick the smaller magnitude
            u = u_par * s_hat - r_star * alpha / A
        else:
            need_boundary = True
    else:
        need_boundary = True

    # ---------- boundary (quadratic) branch ----
    if 'need_boundary' in locals():
        # Solve (7)
        c2 = p_par**2 - B**2
        c1 = 2 * d * p_par
        c0 = d**2 - B**2
        # choose sign so that c1 has same sign as p_par
        if p_par < 0: c1 = -c1
        roots = np.roots([c2, c1, c0]) if abs(c2) > tol else [-c0/c1]
        u_par = None
        for r in roots:
            r = np.real_if_close(r)
            if abs(r.imag) < tol and -1 <= r.real <= 1:
                if feasible(r.real):
                    u_par = float(r.real); break
        if u_par is None:
            raise RuntimeError("No feasible point found (check d)")
        r_mag = np.sqrt(1 - u_par**2)
        u = u_par * s_hat - r_mag * alpha / A

    # ---------- final point --------------------
    c = a + m * u
    return c

7. What to remember

  1. Project everything away from the line first.
    Only the perpendicular components influence the distance.

  2. The best direction in the perpendicular subspace is always directly toward (or away from) that projection.

  3. After this reduction the original n-D problem collapses to one variable (u∥). You either succeed with the unconstrained minimiser or you sit on the boundary |u·p̂| = d, which boils down to the quadratic (7).

That gives you an analytic solution that is numerically trivial to evaluate and works in any dimension n.

python
import numpy as np


def closest_c(a, b, s, m, d, *, atol=1e-12):
    """
    Find c that minimises distance to the line (0,s)
    under
        |c - a| = m,
        | < (b-a)/m , (c-a) > | <= d    (0 <= d <= 1).
    Works in any dimension.
    """
    a, b, s = map(np.asarray, (a, b, s))
    if m <= 0:          raise ValueError("m must be positive")
    if not (0 <= d <= 1 + atol):
        raise ValueError("d must lie in [0,1]")

    # --- prepare unit directions
    p_hat = (b - a) / m
    s_hat = s / np.linalg.norm(s)

    # components parallel / orthogonal to the line
    a_par = np.dot(a, s_hat)
    alpha = a - a_par * s_hat          # ⟂ ŝ
    A = np.linalg.norm(alpha)          # distance of a from the line

    p_par = np.dot(p_hat, s_hat)
    beta  = p_hat - p_par * s_hat      # ⟂ ŝ
    B     = 0.0 if A < atol else np.dot(beta, alpha) / A

    def feasible(x):
        """True if |x p_par - r B| <= d  (within tolerance)."""
        r = np.sqrt(max(0.0, 1.0 - x * x))
        return abs(x * p_par - r * B) <= d + atol

    # ---------- try the unconstrained minimiser ----------
    if A >= m:                 # sphere outside the line
        x_star = 0.0
        if feasible(x_star):
            r = 1.0
            u = -alpha / A                     # direction toward the line
            c = a + m * u
            return c
    else:                       # line cuts the sphere: distance can be 0
        r_star = A / m
        x_opts = (+np.sqrt(1.0 - r_star**2), -np.sqrt(1.0 - r_star**2))
        for x_star in x_opts:                  # choose the sign that works
            if feasible(x_star):
                r = r_star
                u = x_star * s_hat - r * alpha / A
                c = a + m * u
                return c
        # If neither sign is feasible we continue to boundary solve.

    # ---------- boundary: | x p_par - r B | == d ----------
    sols = []
    c2 = p_par * p_par + B * B         # **fixed sign**
    c0 = d * d - B * B

    for sigma in (+1, -1):
        c1 = -2.0 * sigma * d * p_par  # note the overall minus (matches above)
        if c2 < atol:                  # degenerate to linear
            if abs(c1) < atol:
                continue               # no information in this branch
            x = -c0 / c1
            if -1.0 <= x <= 1.0 and feasible(x):
                sols.append(x)
        else:
            disc = c1 * c1 - 4.0 * c2 * c0
            if disc < -atol:
                continue
            disc = max(0.0, disc)
            for root in ( (-c1 + np.sqrt(disc)) / (2*c2),
                           (-c1 - np.sqrt(disc)) / (2*c2) ):
                if -1.0 <= root <= 1.0 and feasible(root):
                    sols.append(root)

    if not sols:
        raise RuntimeError("No feasible root found – check d and inputs.")

    # pick the root that gives the smaller distance
    def dist(x):
        return abs(A - m * np.sqrt(max(0.0, 1.0 - x * x)))
    x_best = min(sols, key=dist)
    r_best = np.sqrt(1.0 - x_best * x_best)
    u_best = x_best * s_hat - r_best * alpha / A
    return a + m * u_best

Why it won’t fail any more

  • The “ + ’’ in the quadratic guarantees at least one real root unless d < |B| and p_par = 0 (in which case the unconstrained minimiser already worked).

  • Every candidate root is re-checked by feasible, so floating-point noise can’t sneak through.

  • At worst the boundary branch always returns one admissible c (the one that sits exactly at |u·p̂| = d and is closest to the line).

import numpy as np


def closest_c_ge(a, b, s, m, d, *, atol=1e-12):
    """
    Closest point c to the line (0, s) such that
        |c - a|      = m          (m > 0),
        |⟨ (b-a)/m , c-a ⟩| >= d  (0 <= d <= 1).

    Works in any dimension.
    """
    # --- input checks -------------------------------------------------
    a, b, s = map(np.asarray, (a, b, s))
    if m <= 0:
        raise ValueError("m must be positive")
    if not (0 <= d <= 1 + atol):
        raise ValueError("d must lie in [0, 1]")

    # --- basic vectors ------------------------------------------------
    p_hat = (b - a) / m
    s_hat = s / np.linalg.norm(s)

    a_par = np.dot(a, s_hat)
    alpha = a - a_par * s_hat          # component ⟂ line
    A     = np.linalg.norm(alpha)

    p_par = np.dot(p_hat, s_hat)
    beta  = p_hat - p_par * s_hat
    B     = 0.0 if A < atol else np.dot(beta, alpha) / A

    # helper -----------------------------------------------------------
    def feasible(x):
        """True if |x p_par - r B| >= d (within tol)."""
        r = np.sqrt(max(0.0, 1.0 - x * x))
        return abs(x * p_par - r * B) + atol >= d

    # distance for a given x (= u_parallel)
    def dist(x):
        return abs(A - m * np.sqrt(max(0.0, 1.0 - x * x)))

    # -- 1. try the unconstrained minimiser ----------------------------
    if A >= m:                      # sphere outside the line
        x_star = 0.0                # r = 1
        if feasible(x_star):
            u = -alpha / A          # direction toward the line
            return a + m * u
    else:                           # line cuts the sphere
        r_star = A / m
        for x_star in (+np.sqrt(1 - r_star**2), -np.sqrt(1 - r_star**2)):
            if feasible(x_star):
                u = (
                    x_star * s_hat                    # parallel part
                    - r_star * alpha / A              # perpendicular
                )
                return a + m * u
        # otherwise fall through to the boundary solve

    # -- 2. boundary | … | = d  ---------------------------------------
    sols = []
    c2 = p_par * p_par + B * B          # NOTE:  “+”, not “-”
    c0 = d * d - B * B

    for sigma in (+1, -1):              # σ chooses the sign inside the |·|
        c1 = -2.0 * sigma * d * p_par
        if c2 < atol:                   # degenerates to linear
            if abs(c1) < atol:
                continue
            x = -c0 / c1
            if -1 <= x <= 1 and feasible(x):
                sols.append(x)
        else:
            disc = c1 * c1 - 4.0 * c2 * c0
            if disc < -atol:
                continue
            disc = max(0.0, disc)
            for root in (
                (-c1 + np.sqrt(disc)) / (2 * c2),
                (-c1 - np.sqrt(disc)) / (2 * c2),
            ):
                if -1 <= root <= 1 and feasible(root):
                    sols.append(root)

    if not sols:
        raise RuntimeError("No feasible point found (check inputs)")

    # pick boundary root giving the smallest distance
    x_best = min(sols, key=dist)
    r_best = np.sqrt(1.0 - x_best * x_best)
    u_best = x_best * s_hat - r_best * alpha / A
    return a + m * u_best

import numpy as np


def closest_c_ge_pos(a, b, s, m, d, *, atol=1e-12):
    """
    Closest point c to the line (0,s) such that
        |c - a|          = m   (m > 0),
        ⟨(b-a)/m , c-a⟩  >= d  (0 ≤ d ≤ 1).

    *No absolute value* on the dot–product.
    Works in any dimension.
    """
    # ---------- basic vectors ----------------------------------------
    a, b, s = map(np.asarray, (a, b, s))
    if m <= 0:
        raise ValueError("m must be positive")
    if not (0 <= d <= 1 + atol):
        raise ValueError("d must lie in [0,1]")

    p_hat = (b - a) / m
    s_hat = s / np.linalg.norm(s)

    a_par = np.dot(a, s_hat)
    alpha = a - a_par * s_hat          # ⟂ line
    A     = np.linalg.norm(alpha)

    p_par = np.dot(p_hat, s_hat)
    beta  = p_hat - p_par * s_hat
    B     = 0.0 if A < atol else np.dot(beta, alpha) / A

    # ---------- helpers ----------------------------------------------
    def dot_val(x):                    # x = u_parallel
        r = np.sqrt(max(0.0, 1.0 - x * x))
        return x * p_par - r * B       # = ⟨p̂ , u⟩

    def feasible(x):
        return dot_val(x) + atol >= d

    def dist(x):
        return abs(A - m * np.sqrt(max(0.0, 1.0 - x * x)))

    # ---------- 1.  try unconstrained minimiser ----------------------
    if A >= m:                         # sphere outside the line
        x_star = 0.0                   # r = 1
        if feasible(x_star):
            u = -alpha / A
            return a + m * u
    else:                              # line intersects the sphere

            if feasible(x_star):
                u = x_star * s_hat - r_star * alpha / A
                return a + m * u

    # ---------- 2. boundary  ⟨p̂ , u⟩ = d  ---------------------------

    c1 = -2.0 * d * p_par
    c0 = d * d - B * B

            if -1 <= x <= 1 and feasible(x):
                sols.append(x)

        if disc < -atol:

        disc = max(0.0, disc)
        for root in (
            (-c1 + np.sqrt(disc)) / (2 * c2),
            (-c1 - np.sqrt(disc)) / (2 * c2),
